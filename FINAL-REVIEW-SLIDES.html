Front End Modules • Terminal Components (Part 1)

Component breakdown and user interface architecture

1. Market Data Panel (Component 1)

Streaming Feed
  • • Header with Market Breadth counters (Advance / Decline ratio)
  • • Real-time search & filter bar with sub-string company lookup
  • • 20 active tier-1 instruments with Bid, Ask, Spread, Change, Volume
  • • Live feed pause/resume toggle with color-flashing quote updates

2. Order Book & Depth (Component 2)

Trading Ladder
  • • Dual-sided visual depth ladder (Bids in Green, Asks in Red)
  • • Interactive order entry ticket (Buy/Sell, Limit Price, Size)
  • • Active working order queue with 1-click cancellation mechanism
  • • Order matching simulation updating trades and VWAP in real time

3. Surveillance Panel (Component 3)

Detection Hub
  • • 7 top KPI summary cards including Predictor Accuracy (94.2%)
  • • Detection sensitivity slider and risk threshold spinner controls
  • • Real-time monospace activity scan log and session detection table
  • • Dedicated "Simulate Abuse Burst" button for instant live demo testing

4. Alerts Queue (Component 4)

Triage Queue
  • • Triage queue with multi-tier severity coloring (Critical, High, Medium)
  • • Split-pane forensic inspector: Detail, Evidence, and History tabs
  • • Workflow transition buttons: Mark Reviewed, Close Alert, Escalate
  • • Severity distribution histogram bars for compliance reporting
